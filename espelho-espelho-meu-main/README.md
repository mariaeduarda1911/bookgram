# Bookgram

O **Bookgram** é uma aplicação web inspirada em redes sociais, com foco no compartilhamento de conteúdos relacionados a livros e leituras.

## Funcionalidades

- Feed de publicações
- Curtir e descurtir posts
- Contagem de curtidas
- Visualização e publicação de comentários
- Reviews de livros
- Perfis de usuários
- Seguir e deixar de seguir usuários
- Contagem de seguidores
- Sugestões de leitores
- Layout responsivo

## Tecnologias

- React
- JavaScript
- HTML
- CSS
- Vite
- React Icons
- JSON

## Como executar

Instale as dependências:

```bash
npm install
```

Execute o projeto:

```bash
npm run dev
```

O projeto será disponibilizado pelo Vite em um endereço local.

## Organização dos dados

Os posts, reviews e usuários são armazenados em arquivos JSON, facilitando a edição e adição de conteúdos sem precisar alterar a lógica principal da aplicação.

## Objetivo

Criar uma experiência de rede social voltada para leitores, permitindo compartilhar conteúdos, interagir com publicações e acessar perfis de outros usuários.
